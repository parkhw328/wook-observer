# 웹 화면과 연결 등록

## 색상과 아이콘

1.3.0은 한화의 주황색 계열과 밝은 배경을 참고한다. 기준 주황색은 `#F37321`이며 [한화 공식 CI 색상 안내](https://www.hanwhaglobal.co.kr/ko/company/ci)의 RGB 243/115/33을 따른다. 링크와 작은 강조 문자는 더 어두운 `#A64209`, 버튼은 주황 배경에 어두운 글자를 사용한다. 상태별 경고·오류·성공 색은 구분한다.

`observer-mark.svg`는 관측 렌즈·중심점·초점 표시를 조합한 Wook Observer 전용 SVG다. 상단 브랜드·로그인·브라우저 아이콘에 공통 사용한다. `icons.svg`는 대시보드·서버·이력·취약점·갱신·사용자의 의미를 담은 동일한 선 굵기의 아이콘이다. 장식 아이콘은 접근성 트리에서 제외하고 링크의 메뉴 이름으로 기능을 안내한다.

## 글꼴과 가독성

사용자 요청에 따라 1.0.0의 `Inter, Pretendard, Noto Sans KR, 시스템 sans-serif` 계열로 복원했다. 설치된 글꼴을 우선하며 Noto Sans KR 대체 글꼴은 이미지에 포함한다. JetBrains Mono를 본문·입력·주소의 기본 글꼴로 지정하지 않는다. 기존 글꼴 라이선스 파일은 보존한다.

본문·입력 18px, 표·안내 16px 수준을 유지한다. 작은 화면에서 표와 메뉴는 각 영역 안에서 스크롤하고 페이지 전체가 가로로 넘치지 않도록 한다. 모든 글꼴·SVG·스타일은 앱에서 제공하며 외부 CDN을 호출하지 않는다.

## 비밀번호 SSH 등록

1. 서버 주소·포트·접속 계정·비밀번호와 필요한 점검 권한을 입력한다.
2. **연결 정보 저장**을 누르면 서버 지문을 자동 조회한다. 공개 키를 붙여 넣거나 개인 키 파일을 준비할 필요가 없다.
3. 관리자가 확인한 서버 지문과 대조한 뒤 확인 체크와 **지문 확인 후 저장**을 누른다.

기존 대상은 저장된 키를 유지한다. 서버 주소·포트·조회한 키가 바뀌면 확인이 초기화되며, 조회 중 주소를 바꿔도 이전 응답을 사용하지 않는다. 공개 키 직접 입력과 SSH 개인 키 인증은 선택할 수 있다. 이후 서버 키가 바뀌면 SSH 접속을 거부하며 변경된 지문을 확인한 뒤 연결 설정을 갱신한다.
