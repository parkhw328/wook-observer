# 웹 화면과 연결 등록

## 색상과 아이콘

1.3.0은 한화의 주황색 계열과 밝은 배경을 참고한다. 기준 주황색은 `#F37321`이며 [한화 공식 CI 색상 안내](https://www.hanwhaglobal.co.kr/ko/company/ci)의 RGB 243/115/33을 따른다. 링크와 작은 강조 문자는 더 어두운 `#A64209`, 버튼은 주황 배경에 어두운 글자를 사용한다. 상태별 경고·오류·성공 색은 구분한다.

`observer-mark.svg`는 관측 렌즈·중심점·초점 표시를 조합한 Wook Observer 전용 SVG다. 상단 브랜드·로그인·브라우저 아이콘에 공통 사용한다. `icons.svg`는 대시보드·서버·이력·취약점·갱신·사용자의 의미를 담은 동일한 선 굵기의 아이콘이다. 장식 아이콘은 접근성 트리에서 제외하고 링크의 메뉴 이름으로 기능을 안내한다.

## 글꼴과 가독성

사용자 요청에 따라 1.0.0의 `Inter, Pretendard, Noto Sans KR, 시스템 sans-serif` 계열로 복원했다. 설치된 글꼴을 우선하며 Noto Sans KR 대체 글꼴은 이미지에 포함한다. JetBrains Mono를 본문·입력·주소의 기본 글꼴로 지정하지 않는다. 기존 글꼴 라이선스 파일은 보존한다.

본문·입력 18px, 표·안내 16px 수준을 유지한다. 작은 화면에서 표와 메뉴는 각 영역 안에서 스크롤하고 페이지 전체가 가로로 넘치지 않도록 한다. 모든 글꼴·SVG·스타일은 앱에서 제공하며 외부 CDN을 호출하지 않는다.

1.7.0의 자산 관리 화면은 사용자 요청에 따라 별도로 본문·입력 14px, 표 13px, 보조 정보 12px를 사용한다. 본문 최대 1,500px 제한을 해제하고 좌우 여백 20px·패널 여백 16px로 가로 공간을 활용한다.

## Observer 로고

1.7.0은 [사용자가 제공한 참고 로고](https://smartcitysolutionmarket.com/scsm/cmpny/slutnCmpnyView.do?cmpnyId=CMPNY_00000000000402&menuNo=4&searchStartUpAt=N)의 원형 모티프를 바탕으로 주황색 그라데이션과 여섯 곡선이 연결된 자체 링 SVG를 사용한다. 작은 크기에서도 O 형태가 읽히도록 중앙 여백을 확보했다. 외부 이미지를 런타임에 요청하지 않는다.

1.10.1의 왼쪽 네비게이션은 폭 240px(741~1100px 화면에서는 220px), 메뉴 16px로 조정했다. 메뉴 간격과 로고를 함께 줄여 본문 가로 폭을 확보하고 740px 이하에서는 기존 가로 메뉴를 유지한다.

네비게이션 상단은 **로고 + Observer** 한 줄로 표시하며 `wook` 보조 문구를 제거한다. 로그인·모바일 로그인·파비콘에 같은 로고를 적용한다. 프로젝트명·파일명·기존 보고서의 Wook Observer 표기는 유지한다.

## 자산 관리 화면

1.8.0부터 메뉴명은 상단 바의 제목(h1)에서 한 번 표시한다. 본문의 중복 메뉴 제목과 `WORKSPACE / ...` 표기를 제거하고 설명·작업 버튼을 남긴다. 자산 상세의 실제 서버명, 대상 등록/연결 설정 이름과 서비스 운영대장 등의 구역 제목은 h2로 유지한다. 본문 영역은 상단 제목을 접근 가능한 이름으로 참조한다.

1.6.0은 대시보드의 기본 지표를 등록 자산·서비스 후보/등록·운영 절차 보완·자산별 최근 발견/의심으로 구성한다. **자산 관리** 메뉴에서 서버별 자산 정보·서비스 운영대장·최근 점검을 함께 연다.

서비스 표는 기본 **운영 절차** 보기에서 이름·포트·시작/종료/상태 확인·관측 시각을 보여주고 **전체 항목**에서 SW/버전·담당/계정·APP/DATA/LOG·연계/메모까지 펼친다. 1.10.0부터 편집은 최대 1,440px의 별도 창에서 구역별로 수행하고 하단에 저장/취소를 고정한다. 자동 관측과 수기 보완은 별도로 보존하며, 저장 충돌 시 입력을 보존한다. 작은 화면은 표 안에서 가로 스크롤한다.

1.10.1은 **PID · 관측 · 편집**을 별도 열로 분리했다. 관리자 편집 버튼은 가로 스크롤 중에도 오른쪽에 고정하고 USER에게는 편집 열을 만들지 않는다. 포트 셀은 실제 포트만 표시하며 자동 관측·이전 수집·운영 포트 미입력 안내는 마우스오버·키보드 포커스·터치 팝업에 둔다. 운영 포트의 긴 수기 값은 한 줄로 요약하고 팝업에 원문 전체를 표시한다. 관측 상태/시각은 셀에 유지하고 수정 이력은 팝업으로 옮겼다. PID는 최대 3개(긴 PID는 2개)와 추가 개수로 표시한다. APP/DATA/LOG와 연계/메모는 레이블과 값을 같은 줄에 놓아 행 높이를 줄인다.

1.9.0의 **시스템 서비스 항목 제외** 버튼은 표시 컬럼 옆의 독립 토글이다. 처음에는 꺼져 전체 서비스를 보여주고, 켜면 확인 가능한 커널·OS 기본 서비스를 숨기며 제외 건수를 표시한다. 다시 누르면 복원하고 검색/보관 상태와 함께 적용한다. PID는 쉼표 없이 숫자 배지 최대 3개와 추가 개수로 표시하며 상세 팝업에서도 개별 배지를 사용한다. 점검 상세의 PID에도 천 단위 구분자를 넣지 않는다.

네비게이션 하단은 **내부망 점검 플랫폼 (1.12.0)** 한 줄로 표시한다. 별도의 Wook Observer/버전 줄과 메인 화면 하단의 브랜드 푸터는 제거했다.

수집 실패·미수집·미관측을 구분하고 예전 관측값에 기준 시각을 표시한다. [엑셀 분석과 필드 대응](asset-management.md)을 따른다.

## 비밀번호 SSH 등록 절차

1. 서버 주소·포트·접속 계정·비밀번호와 필요한 점검 권한을 입력한다.
2. **연결 정보 저장**을 누르면 서버 지문을 자동 조회한다. 공개 키를 붙여 넣거나 개인 키 파일을 준비할 필요가 없다.
3. 관리자가 확인한 서버 지문과 대조한 뒤 확인 체크와 **지문 확인 후 저장**을 누른다.

기존 대상은 저장된 키를 유지한다. 서버 주소·포트·조회한 키가 바뀌면 확인이 초기화되며, 조회 중 주소를 바꿔도 이전 응답을 사용하지 않는다. 공개 키 직접 입력과 SSH 개인 키 인증은 선택할 수 있다. 이후 서버 키가 바뀌면 SSH 접속을 거부하며 변경된 지문을 확인한 뒤 연결 설정을 갱신한다.

## 현장 수집과 자산 보고서

자산 목록/점검 대상의 **수집 SH / 결과 업로드**에서 스크립트 다운로드 → 현장 실행 → 원본 파일 확인/반영의 세 단계를 제공한다. 미리보기는 호스트명·수집 시각·계정·건수·제한을 표시하고, 기존 호스트명과 다른 경우 서버 확인을 요구한다. 파일/대상 선택이 바뀌면 이전 미리보기를 폐기한다. 업로드 자산은 SSH 입력 없이 생성하며 USER에게는 반입/편집 기능을 표시하지 않는다.

자산 목록/상세의 **MD 보고서**는 문서 형태의 미리보기와 동일 문서 다운로드, 원문 보기를 제공한다. 서버 위치와 실행 절차의 줄바꿈을 보존하고 긴 표/코드가 화면 전체를 넘치지 않도록 한다.

## OS 업그레이드 대상 표시

1.11.0은 기존 KPI 아래에 대상이 있을 때만 작은 종료 안내와 **OS 업그레이드 필요** 버튼을 표시한다. 클릭하면 검색/환경 조건을 초기화하고 해당 자산만 모아본다. 자산 목록의 OS 셀에는 짧은 배지를, 상세·반입 미리보기에는 종료일과 ELS 조건·전환 조치·공식 출처를 표시한다. 색상뿐 아니라 문구로 상태를 구분하며 ADMIN/USER 모두 조회할 수 있다. 서비스 표의 열·PID·포트 팝업과 오른쪽 고정 편집은 유지한다.

1.11.0의 서비스 등록/편집 창은 기존 미분류·미들웨어·애플리케이션·공통·보안·백업 분류와 함께 **웹 서버·데이터베이스·컨테이너·캐시·메시징·인프라**를 제공한다. 운영자가 선택한 구분과 자동 관측 종류(프로세스/컨테이너/소켓)는 별개이며 재점검으로 수기 구분을 덮어쓰지 않는다. 저장 후 표·MD/XLSX에서도 같은 분류명을 표시한다.

## 네트워크 관측과 서비스 숨김 (1.12.0)

자산 상세·업로드 미리보기·점검 상세에 접을 수 있는 네트워크 관측 구역을 제공한다. 요약에는 전체 항목과 TCP ESTABLISHED 수/수집 상태를 표시하고 펼치면 상태 선택·검색·독립적인 시스템/예약/자동 할당 범위 제외 버튼을 사용한다. 기본은 전체 표시이며 50행 단위 페이지와 표 내부 스크롤을 제공한다. 로컬/상대 주소를 구분하고 PID는 3개와 추가 개수, 전체는 title/포커스로 확인한다. 구형 파일은 TCP 연결 미수집으로 명시한다.

서비스 편집 체크박스는 **기본 목록에서 숨기기**로 표시하고 ‘삭제하지 않음·집계 제외·숨긴 서비스에서 복원·내보내기 포함’을 설명한다. 필터 **숨긴 서비스**, 행 배지 **숨김**, 보고서 **기본 목록 표시**로 용어를 맞췄다.
