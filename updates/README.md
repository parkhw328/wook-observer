# 폐쇄망 업데이트 반입 폴더

운영용 OSV JSON/ZIP 또는 `wook-catalog-1` 파일을 이 폴더에 복사합니다. 관리자 → 데이터 업데이트에서 파일명(예: `catalog.json`)을 저장하고 즉시 갱신하거나 정기 실행을 켜세요. 파일은 Git에서 제외되며 컨테이너에 읽기 전용으로 연결됩니다.

반입 중인 파일을 읽지 않도록 임시 파일로 복사한 뒤 같은 파일시스템에서 이름을 변경하세요. 앱 UID 10001이 파일을 읽을 수 있어야 합니다. 상세 형식과 용량 제한은 [카탈로그 문서](../docs/catalog.md)를 참조하세요.
